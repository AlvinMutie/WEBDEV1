d) Brief Description of the Website
This project is a responsive website for the JKUAT Robotics Club. It has six
pages that are all linked through the same navigation menu:

  1. index.html       - Home page with an introduction to the club, a summary
                        of what the club offers and a spotlight image.
  2. about.html       - Club history, mission, core values, club leadership
                        and links to external robotics organizations.
  3. activities.html  - Weekly build session timetable (HTML table) and a list
                        of the annual competitions the club takes part in.
  4. gallery.html     - Photo gallery with six captioned images.
  5. membership.html  - Membership registration form with HTML5 validation.
  6. contact.html     - Club location, contact details and online links.

The site is built with HTML5 and CSS3 (external stylesheet in css/style.css).
A small JavaScript file (js/script.js) handles the mobile menu and the form
success message. The layout uses CSS Grid and Flexbox and adapts to mobile
screens through a media query.

e) Instructions for Opening the Project
Step 1: Extract the ZIP file.
Step 2: Open the folder SCT221-D1-0168_2026_WebApplicationDevelopmentProject.
Step 3: Double-click index.html (it opens in your default browser). You can
        also right-click the file and choose "Open with" Google Chrome,
        Microsoft Edge since they are the one i used to test and preview the website.
Step 4: Use the navigation menu at the top to move between the six pages.
Step 5: To test the responsive layout, press F12 in Chrome or Edge and use
        the device toolbar (Ctrl+Shift+M) to switch to a mobile viewport.
Step 6: To test the form validation, open the Membership page and try to
        submit the form while it is empty.

The website was thoroughly tested using Microsoft Edge (primary browser) and
Google Chrome (secondary browser) across both desktop (1440px) and mobile
(375px) viewports.
